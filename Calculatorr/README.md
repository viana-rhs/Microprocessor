### فایل راهنمای کد ماشین حساب سریال

#### معرفی کد

این کد یک ماشین حساب ساده برای انجام عملیات ریاضی (+، -، *، /) از طریق ارتباط سریال است. شما می‌توانید دو عدد و یک عملگر را از طریق مانیتور سریال ارسال کرده و نتیجه عملیات را دریافت کنید.

---

#### نحوه اتصال

1. این کد نیاز به سخت‌افزار اضافی ندارد و فقط از مانیتور سریال برای دریافت و ارسال داده استفاده می‌کند.
2. آردوینو را به کامپیوتر متصل کرده و مانیتور سریال را باز کنید.

---

#### توضیح بخش‌های کد

1. **تعریف متغیرها:**
   ```cpp
   float num1;
   float num2;
   float result;
   char operand;
   ```
   - `num1` و `num2`: اعداد ورودی برای عملیات ریاضی.
   - `result`: نتیجه عملیات ریاضی.
   - `operand`: عملگر ریاضی (+، -، *، /).

2. **تابع setup():**
   ```cpp
   void setup() {
     Serial.begin(9600);
     Serial.println("Operation Example:Number1+Number2");
   }
   ```
   - نرخ انتقال داده سریال روی 9600 تنظیم شده است.
   - پیام راهنما برای کاربر چاپ می‌شود تا فرمت ورودی را بداند.

3. **تابع loop():**
   این تابع منتظر دریافت ورودی از مانیتور سریال می‌ماند و عملیات مورد نظر را انجام می‌دهد.

   - **خواندن ورودی:**
     ```cpp
     while (Serial.available() > 1) {
       num1 = Serial.parseFloat();
       operand = Serial.read();
       num2 = Serial.parseFloat();
     }
     ```
     مقادیر عددی و عملگر ریاضی از ورودی سریال خوانده می‌شوند.

   - **انجام عملیات ریاضی:**
     عملیات ریاضی با استفاده از یک بلوک `switch` انجام می‌شود:
     ```cpp
     switch (operand) {
       case '+':
         result = num1 + num2;
         break;
       case '-':
         result = num1 - num2;
         break;
       case '/':
         if (num2 == 0) {
           Serial.println("Error : Division by zero is not allowed");
           break;
         } else {
           result = num1 / num2;
         }
         break;
       case '*':
         result = num1 * num2;
         break;
       default:
         Serial.println("Error Input");
         result = 0;
     }
     ```
     - برای هر عملگر، عملیات مربوطه انجام می‌شود.
     - در صورت وارد کردن یک عملگر نامعتبر، پیام خطا چاپ می‌شود.
     - در تقسیم، بررسی می‌شود که مخرج صفر نباشد.

   - **نمایش نتیجه:**
     ```cpp
     Serial.print(num1);
     Serial.print(operand);
     Serial.println(num2);
     Serial.print("Result=");
     Serial.println(result);
     Serial.println("Operation Example:Number1+Number2");
     ```
     نتیجه عملیات همراه با ورودی کاربر در مانیتور سریال نمایش داده می‌شود.

---

#### نحوه استفاده

1. کد را در نرم‌افزار Arduino IDE کپی کرده و روی برد آردوینو آپلود کنید.
2. مانیتور سریال را باز کنید و نرخ انتقال داده را روی `9600 baud` تنظیم کنید.
3. دستورالعمل‌ها را به فرمت زیر وارد کنید:
   - مثال: `12.5+7.3`
   - مثال: `15/3`
4. نتیجه عملیات در مانیتور سریال نمایش داده می‌شود.

---

#### نکات مهم

- فرمت ورودی باید به شکل `عدد1عملگرعدد2` باشد (بدون فاصله).
- در صورت وارد کردن عملگر نامعتبر یا تقسیم بر صفر، پیام خطا نمایش داده می‌شود.
- دقت داشته باشید که اعداد اعشاری پشتیبانی می‌شوند.
- برای جلوگیری از مشکلات ارتباطی، مطمئن شوید که فقط از مانیتور سریال برای ارسال دستورات استفاده می‌کنید.
