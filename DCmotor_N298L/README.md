# راهنمای استفاده از کد

## توضیح کلی
این کد برای کنترل سرعت یک موتور DC با استفاده از پتانسیومتر نوشته شده است. در این کد از پین‌های دیجیتال و آنالوگ برای کنترل جهت چرخش و سرعت موتور استفاده می‌شود. مقدار پتانسیومتر خوانده شده و به ولتاژ PWM برای کنترل سرعت موتور تبدیل می‌شود.

## نحوه کارکرد کد
1. **تعریف پین‌ها و تنظیمات اولیه**:
   - پین‌های دیجیتال 9، 8 و 10 به ترتیب به عنوان خروجی تنظیم شده‌اند.
   - پین 9 برای کنترل جهت موتور استفاده می‌شود.
   - پین 8 برای تنظیم جهت مخالف موتور استفاده می‌شود.
   - پین 10 برای تولید سیگنال PWM جهت کنترل سرعت موتور استفاده می‌شود.

2. **حلقه اصلی (loop)**:
   - مقدار ورودی آنالوگ از پین A0 (که به پتانسیومتر متصل است) خوانده می‌شود.
   - مقدار خوانده شده (0 تا 1023) با استفاده از تابع `map` به بازه 0 تا 255 تبدیل می‌شود.
   - موتور در جهت مشخصی (پین 9 روشن و پین 8 خاموش) می‌چرخد.
   - سرعت موتور با استفاده از مقدار تبدیل‌شده از پتانسیومتر تنظیم می‌شود.
   - یک تأخیر 50 میلی‌ثانیه‌ای بین هر خواندن مقدار جدید از پتانسیومتر وجود دارد.

## پیش‌نیازها
- یک برد Arduino (مانند Uno)
- یک موتور DC
- یک ماژول درایور موتور یا مدار H-Bridge
- پتانسیومتر
- منبع تغذیه مناسب برای موتور

## نحوه اتصال سخت‌افزار
1. موتور را به ماژول درایور یا H-Bridge متصل کنید.
2. پین 9 و 8 را به پین‌های ورودی جهت درایور موتور متصل کنید.
3. پین 10 را به پین PWM درایور موتور متصل کنید.
4. پین وسط پتانسیومتر را به پین A0 آردوینو متصل کنید.
5. دو پایه دیگر پتانسیومتر را به GND و 5V متصل کنید.
6. درایور موتور را به منبع تغذیه موتور وصل کنید.

## نکات مهم
- در صورت استفاده از موتورهای با ولتاژ بالا، حتماً از منبع تغذیه جداگانه برای موتور استفاده کنید.
- از یک دیود محافظ در مدار درایور موتور استفاده کنید تا از آسیب به برد آردوینو جلوگیری شود.

## تغییرات پیشنهادی
- افزودن کدی برای تغییر جهت چرخش موتور.
- استفاده از تایمر برای کنترل دقیق‌تر سرعت موتور.
- افزودن نمایشگر برای نشان دادن مقدار سرعت موتور.
