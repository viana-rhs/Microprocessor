### فایل راهنمای کد کنترل LED با بلوتوث

#### معرفی کد

این کد برای کنترل روشن و خاموش کردن یک LED با استفاده از ارتباط بلوتوث طراحی شده است. در این برنامه از کتابخانه SoftwareSerial برای ارتباط با ماژول بلوتوث استفاده شده و دستورات از طریق دستگاه‌های متصل (مانند گوشی موبایل) به ماژول ارسال می‌شوند.

---

#### اتصال‌های سخت‌افزاری

1. **پین‌های ماژول بلوتوث:**
   - RX ماژول بلوتوث به پین 3 آردوینو (TX)
   - TX ماژول بلوتوث به پین 2 آردوینو (RX)
   - GND ماژول بلوتوث به GND آردوینو
   - VCC ماژول بلوتوث به 5V یا 3.3V آردوینو (بسته به مدل ماژول)

2. **پین LED:**
   - پایه مثبت LED به پین 8 آردوینو (از طریق یک مقاومت محدودکننده جریان، معمولاً 220 اهم)
   - پایه منفی LED به GND آردوینو

---

#### توضیح بخش‌های کد

1. **تعریف کتابخانه و متغیرها:**
   ```cpp
   #include <SoftwareSerial.h>
   SoftwareSerial MyBlue(2, 3);  // RX | TX
   String flag;
   int LED = 8;
   ```
   - از کتابخانه SoftwareSerial برای ارتباط سریال با ماژول بلوتوث استفاده شده است.
   - متغیر flag برای ذخیره دستورات دریافت شده تعریف شده است.
   - پین LED به عدد 8 تنظیم شده است.

2. **تابع setup():**
   ```cpp
   void setup() {
     Serial.begin(9600);
     MyBlue.begin(9600);
     pinMode(LED, OUTPUT);
     Serial.println("Ready to connect\nDefualt password is 1234 or 0000");
   }
   ```
   - ارتباط سریال آردوینو و ماژول بلوتوث با نرخ انتقال داده 9600 بیت بر ثانیه تنظیم می‌شود.
   - پین LED به‌عنوان خروجی تعریف شده است.
   - پیام خوش‌آمدگویی برای اطلاع‌رسانی وضعیت ماژول بلوتوث در مانیتور سریال ارسال می‌شود.

3. **تابع loop():**
   این تابع به صورت مداوم بررسی می‌کند که آیا دستوری از طریق بلوتوث دریافت شده است یا خیر.

   - **خواندن دستور از ماژول بلوتوث:**
     ```cpp
     if (MyBlue.available()) {
       flag = MyBlue.readString();
       flag.trim();
     }
     ```
     اگر دستوری دریافت شود، در متغیر flag ذخیره و کاراکترهای اضافی آن حذف می‌شوند.

   - **کنترل روشن و خاموش شدن LED:**
     ```cpp
     if (flag == "1" || flag == "ON" || flag == "on") {
       digitalWrite(LED, HIGH);
       Serial.println("LED On");
     } else if (flag == "0" || flag == "OFF" || flag == "off") {
       digitalWrite(LED, LOW);
       Serial.println("LED Off");
     }
     ```
     - اگر دستور "1" یا "ON" دریافت شود، LED روشن می‌شود و پیام "LED On" در مانیتور سریال چاپ می‌شود.
     - اگر دستور "0" یا "OFF" دریافت شود، LED خاموش می‌شود و پیام "LED Off" در مانیتور سریال چاپ می‌شود.

---

#### نحوه استفاده

1. **اتصالات سخت‌افزاری را برقرار کنید.**
2. کد را در نرم‌افزار Arduino IDE باز کرده و روی برد آپلود کنید.
3. با استفاده از یک اپلیکیشن بلوتوث (مانند Bluetooth Terminal یا Serial Bluetooth Terminal):
   - به ماژول بلوتوث متصل شوید.
   - رمز پیش‌فرض (1234 یا 0000) را وارد کنید.
4. دستورات زیر را از طریق اپلیکیشن ارسال کنید:
   - برای روشن کردن LED: `1` یا `ON` یا `on`
   - برای خاموش کردن LED: `0` یا `OFF` یا `off`

---

#### نکات مهم

- مطمئن شوید که نرخ انتقال داده ماژول بلوتوث با کد تنظیم شده (9600) مطابقت دارد.
- از مقاومت مناسب برای LED استفاده کنید تا از آسیب به آن جلوگیری شود.
- ماژول بلوتوث باید با برد آردوینو هم‌خوانی ولتاژ داشته باشد.
- هنگام آپلود کد، ارتباط پین RX و TX ماژول بلوتوث با آردوینو را قطع کنید.

---

#### نتیجه‌گیری
این کد امکان کنترل LED با استفاده از ارتباط بلوتوث را فراهم می‌کند و به شما اجازه می‌دهد به‌راحتی پروژه‌های مبتنی بر اینترنت اشیا (IoT) را توسعه دهید.
