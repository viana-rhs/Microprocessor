# روشن و خاموش شدن تدریجی یک LED با آردوینو

## مقدمه

این پروژه ساده به شما نشان می‌دهد که چگونه می‌توانید با استفاده از آردوینو و یک LED، یک افکت نوری جذاب ایجاد کنید. در این پروژه، LED به صورت تدریجی روشن و خاموش می‌شود.

## پیش‌نیازها

* یک برد آردوینو (UNO، Nano یا هر مدل دیگری)
* یک LED
* یک مقاومت (مقدار مقاومت به مشخصات LED بستگی دارد، معمولاً بین 220 تا 1000 اهم)
* نرم‌افزار آردوینو IDE (قابل دانلود از سایت رسمی آردوینو)
* کابل USB برای اتصال آردوینو به کامپیوتر

## اتصال مدار

1. یک مقاومت را به یکی از پایه‌های LED وصل کنید.
2. پایه دیگر LED را به یکی از پین‌های دیجیتال آردوینو (در این مثال، پین 6) وصل کنید.
3. پایه‌ی دیگر مقاومت را به زمین (GND) آردوینو وصل کنید.

[در اینجا می‌توانید یک تصویر شماتیک از مدار را قرار دهید]

## کد آردوینو

```c++
int ledPin = 6;  // پینی که LED به آن متصل شده است

void setup() {
  pinMode(ledPin, OUTPUT);  // پین LED را به عنوان خروجی تنظیم می‌کنیم
}

void loop() {
  // روشن کردن تدریجی LED
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    analogWrite(ledPin, brightness);
    delay(30);
  }
  
  // خاموش کردن تدریجی LED
  for (int brightness = 255; brightness >= 0; brightness -= 5) {
    analogWrite(ledPin, brightness);
    delay(30);
  }
}
