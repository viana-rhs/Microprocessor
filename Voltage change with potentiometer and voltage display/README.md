# اندازه‌گیری ولتاژ آنالوگ و نمایش آن روی سریال

## مقدمه
این برنامه ساده از آردوینو برای اندازه‌گیری ولتاژ آنالوگ از پین A0 استفاده می‌کند و نتیجه را روی سریال مانیتور نمایش می‌دهد. این پروژه برای کسانی که می‌خواهند با تبدیل آنالوگ به دیجیتال (ADC) در آردوینو آشنا شوند، مفید است.

## اجزای مورد نیاز
* یک برد آردوینو (مانند Uno، Nano و ...)
* یک پتانسیومتر یا منبع ولتاژ متغیر برای اعمال ولتاژ به پین A0
* نرم‌افزار آردوینو IDE
* کابل USB برای اتصال آردوینو به کامپیوتر

## اتصال قطعات
* یک سر پتانسیومتر را به زمین (GND) آردوینو متصل کنید.
* سر وسط پتانسیومتر را به پین A0 آردوینو متصل کنید.
* سر دیگر پتانسیومتر را به ولتاژ تغذیه آردوینو (5 ولت) متصل کنید.

[در اینجا می‌توانید یک تصویر شماتیک از اتصال قطعات قرار دهید]

## کد آردوینو
```c++
int ledPin = 6;  // پینی که LED به آن متصل شده است (در این مثال استفاده نشده است)
float val = 0;  // متغیری برای ذخیره مقدار خوانده شده از ADC

void setup() {
  pinMode(ledPin, OUTPUT);  // پین LED را به عنوان خروجی تنظیم می‌کنیم (در این مثال استفاده نشده است)
  pinMode(A0, INPUT);  // پین A0 را به عنوان ورودی آنالوگ تنظیم می‌کنیم
  Serial.begin(9600);  // آغاز به کار ارتباط سریال با سرعت 9600 بیت بر ثانیه
}

void loop() {
  // خواندن مقدار آنالوگ از پین A0
  val = analogRead(A0);

  // تبدیل مقدار آنالوگ به ولتاژ و نمایش آن روی سریال
  Serial.print("Voltage is = ");
  Serial.println(val / 1023.0 * 5.0);  // تقسیم بر 1023 برای نرمال‌سازی و ضرب در 5 برای تبدیل به ولتاژ
  delay(1000);  // مکث به مدت 1 ثانیه
}
