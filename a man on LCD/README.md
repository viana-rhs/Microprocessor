### فایل راهنمای کد LCD با انیمیشن کاراکترهای سفارشی

#### معرفی کد
این کد برای نمایش انیمیشن‌هایی از کاراکترهای سفارشی روی نمایشگر LCD طراحی شده است. دو کاراکتر سفارشی با نام‌های "armsDown" و "armsUp" تعریف شده‌اند و با استفاده از پین‌های مشخص، نمایشگر LCD به میکروکنترلر متصل شده است. شدت نور محیط (خوانده شده از سنسور متصل به پین A0) بر سرعت انیمیشن تأثیر می‌گذارد.

---

#### اتصال‌های سخت‌افزاری

1. **پین‌های نمایشگر LCD:**
   - RS: پین 12
   - E: پین 11
   - D4: پین 5
   - D5: پین 4
   - D6: پین 3
   - D7: پین 2

2. **سنسور نور:**
   - متصل به پین A0 (آنالوگ).

---

#### توضیح بخش‌های کد

1. **تعریف پین‌ها و اشیاء LCD:**
   ```cpp
   #include <LiquidCrystal.h>
   int RS = 12;
   int E = 11;
   int D4 = 5;
   int D5 = 4;
   int D6 = 3;
   int D7 = 2;
   LiquidCrystal lcd(RS, E, D4, D5, D6, D7);
   ```
   این بخش پین‌های ارتباطی بین نمایشگر LCD و میکروکنترلر را مشخص می‌کند.

2. **تعریف کاراکترهای سفارشی:**
   دو آرایه بیتی برای نمایش کاراکترهای armsDown و armsUp تعریف شده‌اند:
   ```cpp
   byte armsDown[8] = {
     0b00100,
     0b01010,
     0b00100,
     0b00100,
     0b01110,
     0b10101,
     0b00100,
     0b01010
   };
   byte armsUp[8] = {
     0b00100,
     0b01010,
     0b00100,
     0b10101,
     0b01110,
     0b00100,
     0b00100,
     0b01010
   };
   ```
   این کاراکترها از ماتریس 5x8 بیتی ساخته شده‌اند.

3. **تابع setup():**
   در این قسمت، نمایشگر LCD مقداردهی اولیه می‌شود، کاراکترهای سفارشی ثبت می‌شوند، و صفحه پاک می‌شود:
   ```cpp
   void setup() {
     lcd.begin(16, 2);
     lcd.clear();
     lcd.createChar(3, armsDown);
     lcd.createChar(4, armsUp);
     lcd.setCursor(0, 0);
   }
   ```

4. **تابع loop():**
   این تابع شامل دو بخش اصلی برای حرکت انیمیشن است:

   - **حرکت کاراکتر در سطر بالا:**
     ```cpp
     for (int i = 0; i < 16; i++) {
       if (i > 0) {
         lcd.clear();
       }
       if (i % 2 == 0) {
         lcd.setCursor(i, 0);
         lcd.write(3);
         delay(delayTime);
       } else {
         lcd.setCursor(i, 0);
         lcd.write(4);
         delay(delayTime);
       }
     }
     ```

   - **حرکت کاراکتر در سطر پایین:**
     ```cpp
     for (int j = 15; j >= 0; j--) {
       if (j >= 0) {
         lcd.setCursor(j + 1, 1);
         lcd.write(' ');
       }
       if (j % 2 == 0) {
         lcd.setCursor(j, 1);
         lcd.write(4);
         delay(delayTime);
       } else {
         lcd.setCursor(j, 1);
         lcd.write(3);
         delay(delayTime);
       }
     }
     ```

5. **خواندن ورودی سنسور و تنظیم سرعت انیمیشن:**
   مقدار سنسور از پین A0 خوانده شده و به بازه زمانی تاخیر نگاشت می‌شود:
   ```cpp
   int sensorReading = analogRead(A0);
   int delayTime = map(sensorReading, 0, 1023, 250, 800);
   ```
   هرچه مقدار سنسور بیشتر باشد، تاخیر انیمیشن افزایش یافته و سرعت کاهش می‌یابد.

#### اجرای کد
1. اتصالات سخت‌افزاری را مطابق توضیحات بالا انجام دهید.
2. کد را در نرم‌افزار Arduino IDE کپی کرده و روی برد آپلود کنید.
3. با تغییر میزان نور محیط، سرعت حرکت انیمیشن را مشاهده کنید.

- از نمایشگر LCD با اندازه 16x2 استفاده کنید.
