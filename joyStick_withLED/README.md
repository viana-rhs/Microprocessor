
# پروژه کنترل LED با استفاده از جوی استیک

این پروژه به کمک یک جوی استیک (Joystick) به خواندن مقدار تغییرات محور X آن می‌پردازد و شدت روشنایی یک LED را براساس این تغییرات کنترل می‌کند.

## سخت‌افزار مورد نیاز:
1. برد آردوینو (Arduino)
2. یک جوی استیک
3. یک LED
4. مقاومتی برای LED (در صورت نیاز)

## توضیحات کد:
این کد به طور ساده ورودی‌های جوی استیک را از پین‌های آنالوگ X و Y می‌خواند و از مقدار محور X برای تغییر شدت روشنایی LED استفاده می‌کند.

### عملکرد کد:
1. **تعریف پین‌ها**:
   - پین شماره 7 به عنوان ورودی برای دکمه جوی استیک (SW_pin) استفاده می‌شود.
   - پین‌های 0 و 1 به ترتیب برای محور X و Y جوی استیک (X_pin و Y_pin) استفاده می‌شوند.
   - پین شماره 8 برای اتصال LED به کار می‌رود.
   
2. **در `setup()`**:
   - پین‌ها به طور مناسب تنظیم می‌شوند.
   - پین دکمه جوی استیک به عنوان ورودی تنظیم می‌شود و یک ولتاژ داخلی (HIGH) به آن داده می‌شود تا از تداخل سیگنال جلوگیری شود.
   - اتصال سریال برای نمایش داده‌ها از طریق پورت سریال (Serial Monitor) تنظیم می‌شود.
   
3. **در `loop()`**:
   - مقدار محور X از جوی استیک خوانده می‌شود.
   - سپس این مقدار از دامنه 0 تا 1023 (مقدار آنالوگ خوانده شده) به دامنه 0 تا 255 (مقدار قابل استفاده برای تنظیم شدت نور LED) نقشه‌گذاری می‌شود.
   - این مقدار جدید به عنوان شدت نور LED به پین LED ارسال می‌شود.
   - در نهایت، یک تأخیر 120 میلی‌ثانیه‌ای برای جلوگیری از خواندن پیوسته و بهبود عملکرد اضافه می‌شود.

### توابع اصلی:
- `analogRead(pin)`: برای خواندن مقدار آنالوگ از پین مشخص‌شده (برای خواندن مقدار از جوی استیک).
- `map(value, fromLow, fromHigh, toLow, toHigh)`: برای تبدیل مقادیر از یک دامنه به دامنه دیگر (تبدیل مقدار خوانده‌شده از جوی استیک به یک مقدار مناسب برای تنظیم شدت نور LED).
- `analogWrite(pin, value)`: برای ارسال یک مقدار آنالوگ (پالس عرضی) به پین LED و کنترل شدت نور.

## نحوه اتصال:
1. پین X جوی استیک به پین A0 آردوینو.
2. پین Y جوی استیک به پین A1 آردوینو.
3. پین دکمه جوی استیک به پین 7 آردوینو.
4. پین مثبت LED به پین 8 آردوینو و پین منفی LED به GND.

## نتیجه:
زمانی که جوی استیک را به سمت چپ یا راست حرکت دهید، شدت روشنایی LED تغییر خواهد کرد. مقدار آنالوگ جوی استیک به طور مستقیم بر روشنایی LED تأثیر می‌گذارد.
